一、指揮 AI 輸出 Fortran 程式並完成編譯（20分）

成功引導 AI 生成一個計算 1 加到 N 的 Fortran 程式，並在本地端透過 gfortran 成功完成編譯與執行。

program sum_to_n
    implicit none
    integer :: n, i, total_sum
    
    print *, "請輸入一個整數 N:"
    read *, n
    
    total_sum = 0
    do i = 1, n
        total_sum = total_sum + i
    end do
    
    print *, "從 1 加到 ", n, " 的總和為: ", total_sum
end program sum_to_n

編譯與執行指令：

gfortran sum_1_to_n.f90 -o sum_to_n
./sum_to_n

三、Git 版本控制與 AI 逐行註解（20分）

首先將原版程式碼進行 Git 本地初始化並進行第一次提交（commit）。之後指揮 AI 對原始碼進行逐行註解，經重新編譯驗證成功後，再次認錄（commit）為新版本。

AI 逐行註解後的新版程式碼：

program sum_to_n
    implicit none
    integer :: n, i, total_sum  ! 宣告變數：n為上限，i為計數器，total_sum為累加總和
    
    print *, "請輸入一個整數 N:"  ! 提示使用者輸入資料
    read *, n                    ! 讀取使用者輸入的數值並存入變數 n
    
    total_sum = 0                ! 初始化總和變數為 0
    do i = 1, n                  ! 啟動 do 迴圈，i 從 1 遞增到 n
        total_sum = total_sum + i ! 將當前的 i 值累加到 total_sum 當中
    end do                       ! 結束迴圈
    
    print *, "從 1 加到 ", n, " 的總和為: ", total_sum ! 輸出最終計算結果
end program sum_to_n
